
# Портфолио инженера по тестированию (Junior Manual QA)

Добро пожаловать в мой практический репозиторий. Здесь собраны примеры тестовой документации и проверок веб-приложений и API, выполненных в рамках подготовки к работе в сфере обеспечения качества (QA).

## 🛠 Стек инструментов и навыки
* **Тестовая документация:** Чек-листы, тест-кейсы, баг-репорты, техники тест-дизайна (классы эквивалентности, граничные значения).
* **Веб-тестирование:** Chrome DevTools (Elements, Console, Network, адаптивная вёрстка).
* **Тестирование API:** Postman (методы `GET`, `POST`, работа с JSON, статус-коды `200`, `404`, позитивные и негативные сценарии).
* **Базы данных:** Базовый SQL (`SELECT`, `WHERE`, `JOIN`).
* **Доменная экспертиза:** E-commerce, бизнес-логика маркетплейсов (опыт управления магазинами на Wildberries).
