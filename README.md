
# Портфолио инженера по тестированию (Junior Manual QA)

Добро пожаловать в мой практический репозиторий. Здесь собраны примеры тестовой документации и проверок веб-приложений и API, выполненных в рамках подготовки к работе в сфере обеспечения качества (QA).

## 🛠 Стек инструментов и навыки
* **Тестовая документация:** Чек-листы, тест-кейсы, баг-репорты, техники тест-дизайна (классы эквивалентности, граничные значения).
* **Веб-тестирование:** Chrome DevTools (Elements, Console, Network, адаптивная вёрстка).
* **Тестирование API:** Postman (методы `GET`, `POST`, работа с JSON, статус-коды `200`, `404`, позитивные и негативные сценарии).
* **Базы данных:** Базовый SQL (`SELECT`, `WHERE`, `JOIN`).
* **Доменная экспертиза:** E-commerce, бизнес-логика маркетплейсов (опыт управления магазинами на Wildberries).

## 📂 Содержание репозитория
1. **[Ecommerce_API_Tests.postman_collection.json](./Ecommerce_API_Tests.postman_collection.json)** — Коллекция запросов в Postman для проверки REST API интернет-магазина (получение данных, создание карточки товара, обработка ошибки `404 Not Found`).
 2. **[Checklist_and_TestCases_WB.md](./Checklist_and_TestCases_WB.md)** — Чек-лист и подробные тест-кейсы для проверки поиска, фильтрации и адаптивной вёрстки маркетплейса Wildberries (подтверждено скриншотом [network_filter_200.png](./network_filter_200.png)).
3. **[2. Bug_Reports.md](./2.%20Bug_Reports.md)** — Баг-репорт по выявленному дефекту сетевого запроса (ошибка CORS в консоли Chrome DevTools) с приложенным скриншотом.
4. 4. **[QA_Portfolio_Wildberries_Docs-v3 xisx.xlsx](./QA_Portfolio_Wildberries_Docs-v3%20xisx.xlsx)** — Тестовая документация в формате Excel (сводный чек-лист, тест-кейсы и 3 баг-репорта по витрине и порталу селлера Wildberries).
   5. 5. **[SQL_Queries_Practice.md](./SQL_Queries_Practice.md)** — Примеры проверочных SQL-запросов (`SELECT`, `WHERE`, `GROUP BY`, `INNER/LEFT JOIN`) для тестирования целостности базы данных интернет-магазина.
6. **[Mobile_Testing_Checklist.md](./Mobile_Testing_Checklist.md)** — Чек-лист тестирования мобильного приложения Wildberries на платформе iOS (сетевые сценарии, прерывания, фоновый режим и push-уведомления).
7. 7. **[Test_Plan_WB_Seller.md](./Test_Plan_WB_Seller.md)** — Базовый тест-план для B2B-портала продавца Wildberries (цели, границы проверок Scope/Out of Scope, критерии и оценка бизнес-рисков).
   8. 8. **[Incident_Investigation_WB.md](./Incident_Investigation_WB.md)** — Расследование серверных инцидентов Wildberries (анализ логов через `grep` с контекстом, проверка данных в PostgreSQL по `trace_id` и оформление бэкенд баг-репортов).
      9. 9. **[WB_Incident_Investigation_Table.xlsx](./WB_Incident_Investigation_Table.xlsx)** — Таблица расследования серверных инцидентов Wildberries с фрагментами логов `grep`, SQL-запросами и чек-листом самопроверки.
         10. 10. **[иви_Mobile.xlsx](./иви_Mobile.xlsx)** — Ручное тестирование бета-версии мобильного приложения «Иви» (iOS, TestFlight): чек-лист проверок, тест-кейсы, баг-репорт и итоговая сводка.
