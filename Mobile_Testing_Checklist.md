# Чек-лист мобильного тестирования (iOS): Приложение Wildberries

**Объект тестирования:** Мобильное приложение Wildberries для iOS  
**Окружение:** iPhone 14 Pro, iOS (актуальная версия), Wi-Fi / 4G (LTE)  
**Автор:** Зарина (Junior Manual QA)

| ID | Категория проверки | Что проверяем | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- | :--- |
| **MOB-01** | Сеть и соединение | Переключение с Wi-Fi на мобильный интернет (4G) во время загрузки каталога. | Приложение не вылетает, данные догружаются корректно. | Pass |
| **MOB-02** | Сеть и соединение | Включение «Авиарежима» (потеря сети) при попытке оформить заказ. | Отображается понятное системное уведомление об отсутствии интернета без зависания экрана. | Pass |
| **MOB-03** | Прерывания (Interruptions) | Входящий телефонный звонок или пуш-уведомление в момент ввода адреса доставки. | После завершения звонка приложение возвращается на тот же экран, введённые данные сохраняются. | Pass |
| **MOB-04** | Фоновый режим | Сворачивание приложения на 5–10 минут при заполненной корзине и возврат в него. | Сессия пользователя не сбрасывается, товары в корзине остаются на месте. | Pass |
| **MOB-05** | Интерфейс и жесты | Проверка работы свайпов (смахивание фото в карточке товара, жест «Назад» от края экрана). | Анимация плавная, элементы интерфейса не наезжают на вырез экрана (Dynamic Island). | Pass |
| **MOB-06** | Уведомления (Push) | Нажатие на пуш-уведомление об изменении статуса заказа при закрытом приложении. | Открывается приложение и выполняется прямой переход (Deep Link) на страницу нужного заказа. | Pass |
